# Модели случайных процессов и анализ временных рядов

## Лабораторная работа №1. Моделирование и исследование случайных процессов

Винеровский, пуассоновский процессы и процесс Орнштейна–Уленбека: моделирование траекторий из приращений и точного перехода, ансамблевые среднее, дисперсия и ковариационная матрица в сравнении с теорией, зависимость ошибок от числа траекторий, распределения и зависимость приращений на пересекающихся и непересекающихся интервалах при разных шагах сетки, влияние начального состояния и параметра $\theta$ на процесс ОУ, ансамблевое и временное усреднение.

Отчёт: [`lab1.ipynb`](lab1.ipynb).

## Запуск

```bash
uv run jupyter execute --inplace lab1.ipynb
```

При первом запуске `uv` сам создаст окружение и установит зависимости. Выполнение занимает около 20 секунд.
